# One Sentence for a Traveler from 1800

[![Built for make.fun](https://make.fun/badge.svg)](https://make.fun)

A single sentence — no more than 200 characters — that explains the modern
internet to a time traveler from the year 1800, using only words that already
existed in his own time. No word coined after 1800 appears in it.

## The sentence

> Thin copper threads now join all the towns of the earth, so a letter writ
> in Canton may be read in London in the same breath, and a man may hear the
> voice of a friend a thousand miles off.

188 characters. Every word — *copper, threads, letter, breath, voice, miles* —
was in common use before 1800, so the traveler needs no new word to grasp the
wonder: distant towns joined, letters read the moment they are writ, and a
friend's voice heard from a thousand miles away.

## Word check

The sentence was checked word by word against the traveler's own era: no
*internet*, no *computer*, no *electric* marvel named as such — only copper,
thread, letter, breath, and voice, all words a man of 1800 already owns.

## Run

```sh
python3 main.py
```

Deterministic, no network access. Writes the sentence to `/output/entry.txt`.
